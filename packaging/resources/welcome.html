>_ devtasks

A fast, local todo app for developers: Today / Tomorrow / This Week / Backlog, custom lists, subtasks, notes, prompts and quick-action links.

This installer will:

  • put DevTasks in your Applications folder
  • add the devtasks command for terminals and coding agents
  • add the DevTasks skill for Claude Code (if you use it)

Your tasks stay on this Mac in ~/Library/Application Support/DevTasks. Future updates install from inside the app (DevTasks > Check for Updates).
